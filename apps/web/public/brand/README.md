# PanelJS brand assets

These SVGs reproduce the landing-page mark and can be imported into Figma, Canva, or social-design tools without losing quality.

| Asset                       | Use                                   |
| --------------------------- | ------------------------------------- |
| `paneljs-mark.svg`          | Avatar, favicon, app icon, or sticker |
| `paneljs-logo-dark.svg`     | Logo on a light background            |
| `paneljs-logo-light.svg`    | Logo on a dark background             |
| `paneljs-social-square.svg` | 1200 × 1200 social-post template      |
| `paneljs-social-story.svg`  | 1080 × 1920 story template            |

The social templates contain editable placeholder text: replace `YOUR UPDATE.` or `BUILD IN PUBLIC.` with the post message before exporting.
