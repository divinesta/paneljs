# Getting started

Installation starts by [choosing your framework and ORM](/guide/installation/), or:

```sh
npx paneljs@latest init
```

Express is the HTTP adapter that ships. Prisma, TypeORM, and MikroORM are the data adapters that ship.

- [Express + Prisma](/guide/installation/express/prisma)
- [Express + TypeORM](/guide/installation/express/typeorm)
- [Express + MikroORM](/guide/installation/express/mikroorm)
