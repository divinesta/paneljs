# Fastify

`@paneljs/fastify` is not published yet. Express is the HTTP adapter that ships today.

When Fastify lands, this page becomes the ORM chooser (Prisma / TypeORM / …) and the install steps. Until then, mount with [Express](/guide/installation/express/).

The admin core (`createAdmin`, `register`, schema JSON, UI) will not change. Only `mount` will.
